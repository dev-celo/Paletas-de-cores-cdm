📖 Guia rápido: como usar cada cor

🔴 Vermelho Institucional (#6a0200) usar em: cabeçalhos, barras de navegação, botões principais, bordas de destaque, logo
📊 Excel: use esta cor em títulos de relatórios e células de total
⚪ Cinza Camisa Escritório (#b7b5b6) usar em: fundos de cards, campos desabilitados, linhas de separação
📊 Excel: células neutras ou campos não editáveis
⬜ Off-white Quente (#F5ECD7) usar em: fundo principal de páginas, áreas de leitura, relatórios
📊 Excel: fundo padrão de planilhas para reduzir fadiga visual
⬛ Cinza Carbonizado (#2C2C2C) usar em: textos principais, cabeçalhos de tabela, rodapés
📊 Excel: cor padrão para textos e cabeçalhos de coluna
🟢 Verde Camisa Operacional (#434a2b) usar em: fundos secundários, áreas de leitura prolongada, uniforme digital
📊 Excel: indicadores de "Em andamento" ou células de status médio
🟡 Dourado Nobre (#F5A623) usar em: botões CTA (Chamada para Ação), selos de desconto, conquistas, destaques
📊 Excel: destaque de metas atingidas ou células de sucesso
